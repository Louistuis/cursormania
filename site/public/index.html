faq

questions

is it safe?

yes. it changes only the pictures macOS uses for the cursor, nothing else, and it never needs a password once it's installed. the whole app is open source, so you can check exactly what it does. it uses the same window server calls that tools like mousecape have used for years.

why install with terminal instead of a .dmg?

cursorspacex is free and isn't notarized by apple (that needs a paid developer account), so a downloaded .dmg gets blocked by gatekeeper. the install script fetches the release from github, moves it to applications and opens it. you can read the script before you run it.

how do i go back to the normal cursor?

press restore in the app or pick "restore macOS cursor" in the menu bar. logging out also resets it.

which macs does it work on?

macOS 26 tahoe or newer, on apple silicon and intel. older versions of macOS store cursors differently.

how do i uninstall it?

run curl -fsSL https://csx.lou15.com/install.sh | bash -s uninstall in terminal. it restores the stock cursor and removes the app and its settings.

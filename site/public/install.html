install cursormania

one line in terminal, about thirty seconds.

Terminal
~ % curl -fsSL https://csx.lou15.com/install.sh | bash
downloads v0.3.0 from github, about 2 mb
1

open terminal

press ⌘ space, type terminal and press return.

2

paste the line, press return

copy it from the box above, paste with ⌘ V, then press return.

3

type your mac password

it asks once, to put the app in applications. nothing shows while you type, that's normal. press return and cursormania opens by itself.

why terminal? cursormania is free and open source, and it isn't notarized by apple, so macOS blocks a downloaded app. the script gets the release straight from github, copies it to applications and opens it. nothing else. read the script before you run it if you like.

rather do it by hand? download CursorMania.zip from the latest release, unzip it, drag it into applications, then in system settings open privacy & security and press "open anyway".

uninstall: curl -fsSL https://csx.lou15.com/install.sh | bash -s uninstall puts the stock cursor back and removes the app and its settings.
